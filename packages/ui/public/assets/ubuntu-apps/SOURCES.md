# App icon sources

Retrieved 2026-10-15. These are local source assets; production browsers do not contact icon services.

- Jellyfin, AdGuard Home, Home Assistant, Nextcloud, Pi-hole, Plex, Ollama, Transmission, Tailscale, Uptime Kuma, Portainer, Syncthing, Gitea, Vaultwarden, Immich, n8n, Grafana: upstream Umbrel application gallery, `https://getumbrel.github.io/umbrel-apps-gallery/<app-id>/icon.svg`. Source repository: https://github.com/getumbrel/umbrel-apps-gallery . Retain the repository's existing Umbrel license and notices.
- Docker and Paperless-ngx: https://github.com/homarr-labs/dashboard-icons/tree/main/svg (`docker.svg`, `paperless-ngx.svg`), retrieved through jsDelivr. Upstream Apache 2.0 license is retained in `LICENSE-dashboard-icons`.

Product names and logos belong to their respective owners. No custom logo approximations or generated brand assets are used.
